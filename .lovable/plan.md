# Homepage redesign and live offer ticker

## Goal
Restyle the storefront homepage to follow the attached reference: bright cream canvas, centered Arabic-first headline, compact booking/service selector, generous whitespace, dark forest typography, and restrained gold accents.

## Changes
- Replace the current animated aircraft/ticket hero with a clean centered travel-service hero inspired by the reference, while keeping Gunited Travel branding and bilingual support.
- Make security approval the clearest first action, with flight and border pathways still routed through the required traveller-details screen.
- Recompose the homepage into spacious alternating benefit sections for payment flexibility, live tracking, and fast digital delivery.
- Keep the existing admin-managed content blocks, offers, account actions, and footer functional.
- Add a fixed, slim moving announcement strip at the bottom of the viewport. It will automatically use currently active offers added by administrators, link each offer to its page, support RTL/LTR, pause on interaction, and respect reduced-motion settings.
- Improve mobile sizing and thumb reach without introducing colors outside the existing forest, cream, and gold brand system.

## Validation
- Confirm the homepage at desktop and mobile widths.
- Confirm admin-added active offers appear in the moving strip and each link opens the correct offer.
- Confirm Arabic/English switching, security-approval links, and offer cards still work.
- Check the latest build and browser console for errors.
